## 👋 Merhaba

Ben **Kadir Aydın** — Endüstri Mühendisi ve yazılım geliştirici. Kurumsal BT/altyapı tarafında çalışırken iki ayrı ürün geliştiriyorum:

- **ClinicFlow** — psikolog, diyetisyen, estetisyen ve diğer özel klinikler için randevudan iletişime, web sitesinden sosyal medyaya kadar operasyonu otomatikleştiren SaaS ailesi.
- **SociAgent** — klinik veya sektör ayrımı olmadan, tüm KOBİ'ler, ajanslar ve içerik üreticileri için global bir yapay zeka sosyal medya ekibi.

İkisi de multi-tenant mimariyle çalışır, ayrı ürünlerdir.

### ✨ SociAgent
**Markanı tanır. Ne üreteceğini sen seçersin. Üretir, planlar, yayınlar, reklamı yönetir.**<br/>
<sub>Son karar ve sorumluluk her zaman kullanıcıdadır.</sub>

</div>

SociAgent; planlayıcı + tasarım aracı + video kurgu + reklam yönetimini tek abonelikte birleştiren, **global** bir AI sosyal medya platformudur. Arayüz çok dillidir, içerik her dilde üretilebilir (RTL dahil), kullanıcı başına ücret yoktur.

| | |
|---|---|
| 🧠 **Brand Brain** | Web sitesi URL'sinden logo, renk, font ve marka tonunu otomatik çıkarır; dokümanlarla RAG tabanlı marka hafızası kurar |
| 🎬 **Studio** | Fotoğraf · Carousel · Reels · Story — format ve kaynağı (AI üretsin / kendi medyam / karışık) kullanıcı seçer |
| 📅 **Calendar** | Saat dilimi duyarlı, sürükle-bırak içerik takvimi; en iyi saat önerisi |
| ✅ **Onay Akışı** | Editor → Approver; ajanslar için hesapsız müşteri onay linki |
| 📣 **Reklam Yönetimi** | Meta Ads sihirbazı, özel reklam kategorileri desteği, organik içeriği reklama çevirme (Boost) |
| ⚙️ **Ad Autopilot** | Kural tabanlı (IF-THEN) reklam yönetimi — n8n + Claude Haiku |
| 🤖 **Hermes (Ultra AI)** | Doğal dil komutuyla çalışan canlı reklam ajanı — Nous Hermes Agent + Claude Sonnet |
| 📊 **Insights** | Organik + reklam + dönüşüm performansı, paylaşılabilir raporlar |
| 🛡️ **Compliance Assistant** | Sektör ve ülke kurallarına göre uyarır, yayını engellemez; tüm onaylar kayıt altındadır |
| 🏢 **Workspaces & Roller** | Marka/müşteri bazlı çalışma alanları, ekip rolleri, ajans desteği |
| 📱 **Mobil Uygulama** | iOS + Android — çek, üret, onayla, planla |

**Kanallar:** Instagram + Facebook Sayfası ile başlar; TikTok, LinkedIn, YouTube Shorts, Pinterest, X, Threads sonraki aşamada.

## 🗺️ Ekosistem

ClinicFlow'un üç ürünü tek altyapıda, tek tek de bundle olarak kullanılır. **SociAgent** ise klinik odaklı olmayan, global ve bağımsız ayrı bir üründür.

```mermaid
flowchart TD
    subgraph CF ["🏥 ClinicFlow — Klinikler için"]
        Core("🏥 <b>ClinicFlow Core</b><br/>clinicflow.com.tr<br/>WhatsApp AI · Telefon AI · Randevu · SMS/E-posta")
        Sites("🌐 <b>Site Builder</b><br/>sites.clinicflow.com.tr<br/>Hazır web sitesi şablonları")
        Agent("🤖 <b>ClinicFlow Agent</b><br/>agent.clinicflow.com.tr<br/>Instagram + Meta Ads AI ajanı")
        Bundle("💎 <b>Bundle Abonelik</b><br/>Üç ürün → tek fatura")
        Core --> Sites
        Core --> Agent
        Sites --> Bundle
        Agent --> Bundle
    end

    subgraph SA ["✨ SociAgent — Tüm sektörler, global"]
        Soci("✨ <b>SociAgent</b><br/>sociagent.ai<br/>Studio · Calendar · Brand Brain<br/>Ad Autopilot · Hermes · Insights")
    end

    classDef core fill:#2DB6A3,stroke:#1f8378,color:#ffffff;
    classDef sites fill:#4F86C6,stroke:#37618f,color:#ffffff;
    classDef agent fill:#8B5CF6,stroke:#6d3fc0,color:#ffffff;
    classDef bundle fill:#F59E0B,stroke:#b87708,color:#ffffff;
    classDef soci fill:#F97316,stroke:#c2570c,color:#ffffff;
    class Core core;
    class Sites sites;
    class Agent agent;
    class Bundle bundle;
    class Soci soci;
```
